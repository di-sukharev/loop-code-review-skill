# Finding Adjudication

Use this only for a material evidence-based disagreement about a finding while the scoped state is unchanged.

1. Give the same reviewer the exact counter-evidence and ask once whether the finding should be withdrawn or revised.
2. If disagreement remains material, start one fresh read-only adjudicator without parent history. Provide only the finding, its evidence, the relevant scope, counter-evidence, and validation results. Require a brief evidence-based verdict that upholds the finding or explains why it is invalid.
3. Ask the adjudicator once for missing or ambiguous reasoning. If the verdict remains unusable, stop `incomplete`.

The finding remains unresolved until fixed, withdrawn, or adjudicated invalid. Focused adjudication is not a review pass. Do not rerun a review pass of unchanged state for another opinion.
