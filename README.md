# Loop Code Review

Саб-агенты делают код-ревью в цикле и дожимают реализацию, пока не перестанут находить ошибки.

## Установка

Попросите агента:

```text
Установи этот скилл глобально: https://github.com/di-sukharev/loop-code-review-skill
```

Или скопируйте папку `loop-code-review` в `~/.codex/skills/` или `~/.claude/skills/`.

## Использование

После внесения изменений в той же сессии запустите:

```text
/loop-code-review
```

Модель субагентов можно указать в запросе.
