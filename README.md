# Ревью в цикле

ИИ может срезать углы в собственных реализациях.

Ревью в цикле запускает саб-агентов без контекста, которые делают независимое ревью активных изменений.

Саб-агенты работают в цикле, находят существенные проблемы в реализации и исправляют их.

## Установка

Отправьте агенту это сообщение.

```text
Установи скилл глобально https://github.com/di-sukharev/loop-code-review-skill
```

## Запуск

Напишите `используй ревью в цикле` в чате, где агент писал код.

## Другие скиллы

- [Code Scout](https://github.com/di-sukharev/code-scout-skill) — саб-агент ищет код — дешёвый агент поглупее ищет нужный код и приносит его умному агенту, чтобы тот не тратил свой дорогой контекст.
- [Orchestration](https://github.com/di-sukharev/orchestration-skill) — выполняет несколько крупных задач отдельными саб-агентами: каждый планирует, реализует и запускает независимое ревью через Loop Code Review.
- [Refactoring](https://github.com/di-sukharev/refactoring-skill) — профилактический рефакторинг кода — чистит код от легаси, лишних абстракций, слабых тестов и других жидких реализаций.
