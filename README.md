# Loop Code Review

Свежие саб-агенты находят и исправляют существенные дефекты. Глубина ревью зависит от риска.

## Установка

```text
Установи глобально скилл и Claude-агентов: https://github.com/di-sukharev/loop-code-review-skill
```

Вручную: папку `loop-code-review` скопируйте в `~/.codex/skills/` или `~/.claude/skills/`, файлы `claude-agents/*.md` — в `~/.claude/agents/`. После первой установки агентов перезапустите Claude Code. Без этих агентов субагенты Claude Code наследуют effort сессии и стоят дороже.

## Использование

После изменений в той же сессии запустите:

```text
/loop-code-review
```

- Обычный риск: ревьюер Opus или Sol с effort `medium`. После нетривиальных исправлений — дельта-раунд только по исправлениям.
- Высокий риск (миграции, хранимые данные, безопасность, конкурентность, внешние контракты): effort `high`, после исправлений кода — полный раунд.
- Не больше 3 раундов. Нерешённое попадает в отчёт.

Ваши настройки модели и effort приоритетнее.
