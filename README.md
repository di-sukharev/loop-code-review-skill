# Loop Code Review

Саб-агенты делают код-ревью в цикле и дожимают реализацию, пока не перестанут находить ошибки.

## Установка

Попросите агента:

```text
Установи этот скилл глобально: https://github.com/di-sukharev/loop-code-review-skill
```

Или скопируйте папку `loop-code-review` в `~/.codex/skills/` или `~/.claude/skills/`.

## Использование

После внесения изменений в той же сессии запустите:

```text
/loop-code-review
```

Скилл может запустить и саб-агент, который реализует задачу. Он ведёт ревью и
создаёт нового проверяющего саб-агента для каждого раунда.

Агент выбирает доступные модель и effort по сложности и риску, пересматривая выбор каждый раунд: простые задачи — лёгкая модель и низкий effort, сложные — сильная модель и высокий effort. Явные настройки в запросе приоритетнее.
